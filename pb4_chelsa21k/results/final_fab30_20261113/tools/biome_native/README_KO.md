# BIOME4 원래 생물군계 코드 (2026-11-27)

최종 패키지(`model/PB4Studio_v6.6.3_CHELSA21K.zip`, SHA-256 dec622f7...)를 새로 풀어 `runner.py`에 진단 출력만 추가하고 다시 실행하였다(`runner_output_only.diff`). 추가한 출력은 스냅숏별 `biome4_native.tif`(BIOME4 생물군계 1-28)와 `pft02_npp.tif`-`pft07_npp.tif`(혼효림 판정에 쓰는 PFT별 NPP)이다.

## 동일성
정적, 동적 모델 211개 시점 모두에서 토심, 우점 PFT, 식생유형, NPP, EEMT가 최종 실행(`FINAL_STATE_CUBE.npz`)과 같다(최대 차이 0).
