# 산불잠재일수 점검 (2026-11-27)

최종 패키지의 BIOME4(mckenzie2003 변형)에 일 단위 기록을 넣어, 2.8 ka와 8.0 ka 기후에서 토심만 바꾸어 실행하였다.

- `build.py`: 패키지의 패치 과정을 그대로 거친 소스에 `wet(d)=wr_n` 직후 일별 w1, w2, wr_n, 강수, 융설, AET, 일평균기온, 침루를 쓰는 줄을 넣는다. `gfortran -shared -fPIC -O2 -frecursive -std=legacy patched.f wrapper.f90 -o libdiag.so`로 컴파일.
- `run.py <ka>`: 기준 실행의 월 기후(`reference_run/model_dynamic/monthly_forcing_timeseries.csv`)로 토심 0.02-1.94 m를 실행한다. 출력의 산불잠재일수는 기준 실행 격자 값과 같다.
- `firedays_dry_days_by_month.csv`: PFT 4와 7의 근권 토양수분이 산불 임계값(0.33)보다 낮은 날의 월별 수.

결과
- 건조일은 모두 11-3월에 있고, 4-10월에는 토심 0.02 m에서도 0일이다.
- 건조일의 일평균기온은 모두 0 °C 이하이다(2.8 ka, 0.07 m: −10.3 ~ −0.4 °C). 이 기간 강수는 눈으로 쌓여 토양에 들어오지 않는다.
- BIOME4는 일평균기온이 −10 °C 이하인 날에만 물수지 계산을 멈추므로, −10 ~ 0 °C인 날에는 상층의 침루와 낙엽기 증발(0.25 deq)이 계속된다. 토심이 0.3 m보다 얕으면 하층이 없어 근권 토양수분이 상층 값과 같아지고, 겨울 동안 임계값 아래로 떨어진다. 토심이 깊으면 하층이 젖은 채로 남아 임계값 아래로 내려가지 않는다.
- 산불잠재일수의 최댓값(61일)은 BIOME4 생물군계 판정에 쓰이는 90일보다 작아 식생 판정과 검증 결과에는 영향이 없다.
