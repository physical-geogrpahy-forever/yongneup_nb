## 최종 모델 구성

이전 패키지(U008 + 산불잠재일수 근권 토양수분 정규화)에서 바뀐 것은 세 가지다.

1. **지형 자료와 유역**
   - FABDEM V1-2(Hawker et al., 2022)를 EPSG:5187로 투영한 자료(`../../data/FABDEM_V1-2_yongneup_region_EPSG5187_27p4m.tif`)를 쌍선형 보간하여 30 m 격자로 구성하였다.
   - 유역은 와지를 채운 지형에서 D8 흐름 방향으로 구하였다. 출구는 용늪에서 나가는 유로가 처음 지류와 합류하는 지점 바로 아래이다.
   - 격자 656개, 59.0 ha이며, 고도는 1,138~1,284 m(평균 1,217 m)이다.
   - 초기 토심은 이전과 같은 SoilGrids 1 km 기반암 깊이(1.94 m)이고, 토성은 BIOME4 class 2이다.
   - 만든 방법: `tools/build_fabdem_basin_grid.py` (작업 경로는 당시 작업 공간 기준)
2. **EEMT**: Rasmussen & Tabor (2007)를 따라 월별 EPPT를 유효강수가 양수인 달만 더하고, 0 °C 아래 달은 0으로 둔다. Pelletier & Rasmussen (2009)이 지적한 대로, 영하에서 내린 강수는 풍화에 기여하지 않는다.
   ```python
   peff_mm = np.maximum(P - AET, 0.0)
   dT = np.maximum(T, 0.0)
   EPPT = sum(dT * c_w * peff_mm)
   ```
3. **임계경사**: Pelletier et al. (2013)의 0.7. 30 m 유역의 인접 격자 간 최대 경사가 0.60이므로 원래 값을 그대로 쓴다. 이전 DEM에서 1.5를 쓴 이유(최대 경사 1.33)는 이 지형에 해당하지 않는다.

## 검증 결과

| | 정적 지형 모델 | 동적 지형 모델 |
|:--|--:|--:|
| Jang et al. (2011) | 24/62 | **55/62** |
| 95_03 (3.4~0.39 ka, 활엽수림) | 0/31 | 31/31 |
| Park et al. (2021), 비교 4그룹 일치 시점 (/112) | 91 | **101** |
| 아한대 낙엽수 일치 (/28) | 9 | **19** |
| PFT TSS, 비교 4그룹 (민감도) | 0.688 | 0.718 |

- 동적 지형 모델에서 95_03 구간의 활엽수림 격자는 23~35개로 유역의 3.5~5.3%이다. 출현 기준을 1개에서 20개 격자(3.0%)까지 바꿔도 Jang 55/62가 유지된다.
- PFT7 우점 격자: 5.9 ka 32, 3.4 ka 21, 2.7 ka 19, 1.0 ka 19, 0 ka 17
- Park 검증(2026-11-14 수정, `park_validation/`): 모델 출현 기준을 Jang 비교와 같은 유역 1%로 맞추고, 그룹별 일치 시점 수로 평가한다. 비교 그룹은 온대 낙엽활엽수, 아한대 낙엽수, 상록 침엽수, 온대 상록활엽수이다. 벼과(습원 표면 식생 영향, Park et al., 2021)와 마황속(풍매 장거리 화분, 5%를 넘은 시료 없음)은 참고로만 제시한다. 두 모델의 차이는 아한대 낙엽수뿐이며(정적 9/28, 동적 19/28), 다른 그룹은 같다(28, 26, 28/28). 벼과는 두 모델 모두 3/28이다.
- 이전 판정(1개 격자, 6그룹 합산 TSS 정적 0.522, 동적 0.473)은 11.9 ha 유역에서 정한 1개 격자 기준이 남아 있어, 656격자 유역에서 PFT10 1~2개 격자를 출현으로 셌다. 출현 기준과 그룹 구성에 따른 TSS는 `park_validation/park_tss_sensitivity.csv`.
- 생물군계 판정(Takahara et al., 2000)으로도 비교했으나 72개 시료 중 49개가 난온대 혼효림으로 나와(장거리 난온대 분류군 영향) 쓰지 않았다. 그룹 비율과 모델 격자 수의 시간 상관도 유의하지 않았다(순환 이동 p 0.26 이상).

## 산불잠재일수 (`FIRE_SUMMARY.json`)

- 정적 지형 모델: 모든 격자의 토심이 1 m 이상이고 산불잠재일수는 0일이다.
- 동적 지형 모델 홀로세 토심 구간별 평균(최대):

  | 토심 | 평균 (최대) |
  |:--|--:|
  | 0.05 m 미만 | 34.4일 (49) |
  | 0.05~0.1 m | 49.4일 (56) |
  | 0.1~0.3 m | 35.6일 (61) |
  | 0.3~1 m | 2.5일 (32) |
  | 1 m 이상 | 0일 |

- 3.5~2.0 ka 유역 최대 산불잠재일수는 동적 51~56일, 정적 0일이다(`../../plots/YONGNEUP_FINAL_max_firedays_3p5_2p0ka.png`).
- 4.5~1.0 ka에 토심이 가장 얕은 8개 격자 중 7개는 2.7 ka에 산불잠재일수가 가장 높다(circular shift p 0.06~0.17). 2.8~2.7 ka에 토심이 0.01~0.02 m 두꺼워지면서 NPP가 늘어 연료 보정 값이 커졌기 때문이다.

## 재현 확인

최종 패키지 압축을 새로 풀어 `tools/run_yongneup_21ka_chelsa_selfcontained.py`로 실행하였다(Linux, GNU Fortran 13.3.0, `reference_run/`).

- 임계경사를 0.7로 바꾸기 전 패키지로도 한 번 실행했으며, 검증, PFT 판정, summary 파일이 해상도 비교 실행(run K)과 파일 단위로 같았다.
- 0.7로 바꾼 뒤에는 과학 코드(`climate.py`, `biome4_backend.py`, `runner.py`, `pelletier_geomorph.py`)가 기준 실행(run L)과 같다.
