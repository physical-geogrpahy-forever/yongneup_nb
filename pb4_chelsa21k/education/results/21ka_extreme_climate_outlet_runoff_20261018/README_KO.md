# 용늪 21–0 ka 기후 시나리오별 유출구 유출량 비교

검토일 2026-10-18. 기존 PB4Studio v6.6.3-CHELSA21K BIOME4–Pelletier 결과를 후처리함. 원본 물리계산식 및 매개변수 불변.

## 모델 및 수문자료의 구분

- 유역 20 m, 298개 격자, 모형 면적 119,200 m²(0.1192 km²), 단일 출구 open-free (row=2, col=16).
- 21–0 ka, 100년 간격 211시점, 5개 조건 × 정적·동적 2모델 = 2,110개 모형시점.
- 기후: 기준 CHELSA / 온난습윤 (+4°C, 강수×1.5) / 온난건조 (+4°C, ×0.5) / 한랭습윤 (−4°C, ×1.5) / 한랭건조 (−4°C, ×0.5).
- BIOME4 `runoff_node`는 토양 수분수지의 표층 유출과 하부 토층 배수를 더한 **연유출고(mm/yr)**다. 이것이 하도 라우팅된 유출구 유량은 아니다.
- 특히 토심이 `1e-6 m` 이하인 격자는 원래 `runner.py`가 BIOME4 수문 계산에서 제외한다. 따라서 `summary_timeseries.csv`의 `mean_runoff_mm_yr`는 이 격자들이 빠진 평균이다.

### 두 가지 후처리

1. **211시점 유역면적 외삽 비교지표**: `mean_runoff_mm_yr /1000 × 119200 /(365.2425×86400)` [m³/s]. 계산된 격자의 평균 유출고를 전 유역으로 외삽한 값이므로 실제 물량의 합계/유출구 유량으로 오인해서는 안 된다. 기후 간 같은 기준면적에서 유출고의 강도를 비교하는 용도.
2. **5개 대표시점의 D8 유출구 누적 유출량**: 21·15·10·5·0 ka의 `runoff_mm_yr.tif`와 `elevation_m.tif`를 사용해 PB4Studio 원본 `d8_flow_accumulation_area_multi_boundary`와 동일한 유로상에서 계산 가능한 격자별 연유출량을 유출구로 누적. 유출고 미산정 나지·기반암 격자는 물의 이동을 계산하지 않아 기여를 포함할 수 없다. 즉 **BIOME4 계산 격자만의 연유출 등가량**, 미산정 격자를 0유출로 주장하는 것이 아님. 유수 이동시간·저류·홍수첨두도 계산되지 않음.

## 검증

- 전체 시계열 결측·음의 유출고 없으며 10개 모델의 211시점 완비, 동일 면적 확인.
- 5개 기후 × 대표시점 5개 = **25개의 동적모델 D8 유출구 라우팅**. 매번 지정 출구 집수면적 **119200 m²**, 모든 298개 격자 유로 연결.
- D8 출구 누적 연유출량과 개별 격자 유출량 합계의 최대 잔차 **1.1642×10⁻¹⁰ m³/yr**.
- 0 ka의 BIOME4 유출고 미산정 격자 개수 0/0/22/0/57은 해당 시점 토심 및 유출고 GeoTIFF의 마스크로 직접 확인.
- geomorphic fluvial-erosion 계산은 하도 물유량을 동역학적으로 라우팅하는 수문모형이 아님. 집수면적·하도경사·EEMT 등 지형과정 입력과 BIOME4 연유출고를 혼동하지 않는다.
