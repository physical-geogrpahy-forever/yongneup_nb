# PB4 U008 17.2 ka 초기 침엽수림 불일치 원인 분석 완결

작성일: 2026-10-07  
대상 모델: `PB4Studio v6.6.3-CHELSA21K-FINAL-nativeClimate-BIOME4AGB-U008`

## 1. 결론

17.2 ka의 동적모델에서 정적모델의 침엽수림과 달라진 27셀은 하나의 메커니즘으로 묶으면 안 된다.

- 초본/개방식생 1셀은 토양이 완전히 사라지기 직전의 과도상태이다.
- 무식생 26셀은 토심이 사실상 0이 된 토양 소진 상태이며, 현재 시점에서는 대부분 하도/수렴 위치에 놓이고 기반암 하천침식이 작동한다.
- 따라서 초기 침엽수림 불일치의 주된 경로는 `수렴/하도 집중 -> 토심 및 WHC 붕괴 -> 침엽수 PFT 생산성 저하 -> 개방식생 -> 토양 소진 및 무식생`이다.
- 4 ka 부근의 활엽수림/혼효림 차이처럼 산림 내부의 51% PFT 경쟁 경계를 넘는 메커니즘과는 구분된다.

## 2. 17.2 ka 실제 셀 군 비교

동적모델 298셀은 침엽수림 271셀, 초본/개방식생 1셀, 무식생 26셀이다.

무식생군의 valley 비율은 침엽수림군보다 매우 높다. 2x2 표에서 무식생 대 침엽수림의 valley odds ratio는 약 31.5이다. Fisher exact 검정의 p값은 약 1.98e-12이지만, 격자셀의 공간적 비독립성 때문에 이는 독립 표본에 대한 형식적 추론값이라기보다 공간집중도의 수치적 진단으로만 사용한다.

무식생 26셀 가운데:
- 23셀은 valley로 분류된다.
- 26셀 모두에서 fluvial bedrock erosion이 양수이다.
- fluvial regolith erosion이 양수인 셀은 1셀뿐이다. 나머지는 토양이 이미 거의 소진되어 현재 시점에 제거할 regolith가 없다.
- 23셀에서 hillslope dz가 양수이고 3셀은 0이며 음수인 셀은 없다.
- 동적-정적 고도차는 평균 -2.383 m, 중앙값 -2.385 m, 범위 -2.971~-1.887 m이다.

따라서 17.2 ka의 무식생을 현재 시점의 사면침식으로 직접 설명하는 것은 맞지 않는다. 현재 hillslope term은 오히려 다수 셀에서 양수이며, 무식생 셀은 이미 토양이 소진된 뒤 하천침식이 기반암으로 전환된 상태이다.

## 3. 시간 추적: 초본은 토양 소실 직전의 과도상태

초기 불일치 셀을 17.2 ka 셀과 대조하면 위치가 무작위로 이동하지 않는다.

- 19.8 ka 불일치 4셀은 17.2 ka에 모두 무식생이다. 이 4셀은 17.2 ka 기준으로 모두 valley이다.
- 18.4 ka 불일치 19셀은 17.2 ka에 모두 무식생이다. 이 가운데 18셀은 valley이다.
- 18.3 ka 불일치 19셀도 17.2 ka에 모두 무식생이다.
- 17.2 ka에는 여기에 7개의 무식생 셀이 추가되어 총 26셀이 된다.

직접적인 전환 사례:
- cell (5,12): 19.8 ka에 토심 0.003958 m, WHC 0.938 mm, wetness 61.7, firedays 21 d, NPP 4, optPFT 10의 초본/개방식생이었다. 18.4 ka에는 토심 0 m, NPP 0의 무식생으로 전환되었다.
- cell (9,13): 18.4 ka에 토심 0.001297 m, WHC 0.307 mm, wetness 56.0, firedays 15 d, NPP 4, optPFT 10의 초본/개방식생이었다. 18.3 ka에는 토심 0 m, NPP 0의 무식생으로 전환되었다.

이 두 셀은 `침엽수림 -> 매우 얕은 토심의 개방식생 -> 무식생` 경로가 실제 시계열에서 나타남을 보여준다.

## 4. 17.2 ka 초본 1셀의 PFT 메커니즘

17.2 ka cell (14,9)의 실제 상태:
- 토심 0.009295 m
- WHC 2.203 mm
- wetness 56.7
- firedays 34 d
- NPP 6
- LAI 0.10
- native BIOME4 biome 21
- optPFT 10
- reduced class 3, 즉 초본/개방식생

동일 17.2 ka 기후와 토성을 고정하고 토심만 1.94 m로 둔 직접 BIOME4 재계산은 static 셀과 같은 상태를 재현하였다:
- WHC 298.55 mm
- native biome 8
- optPFT 6
- NPP 276
- LAI 2.45
- reduced class 0, 즉 침엽수림

PFT별 잠재 NPP 변화:
- PFT6: 276.006 -> 56.717, 약 79.45% 감소
- PFT7: 260.564 -> 92.366, 약 64.55% 감소
- PFT10: 77.333 -> 5.972, 약 92.28% 감소

여기서 중요한 점은 PFT10의 NPP가 PFT7보다 커져서 단순 경쟁승리를 한 것이 아니라는 점이다. BIOME4 원 코드에서는 woody dominant가 PFT7일 때 NPP가 120 미만이면 grass/open branch로 이동하고, 이후 grass LAI가 낮고 PFT10이 존재하면 optPFT 10을 선택한다. 17.2 ka 초본 셀의 PFT7 NPP는 92.37로 이 조건 아래에 있다.

19.8 ka의 초본 cell (5,12)에서도 PFT6=36.95, PFT7=57.66, PFT10=4.47이었고, 18.4 ka의 초본 cell (9,13)에서도 PFT6=26.71, PFT7=40.04, PFT10=3.66이었다. 따라서 동일한 내부 판정 경로가 반복된다.

## 5. 17.2 ka 고정기후 토심 민감도: 전환 토심

17.2 ka 기후, 토성 2, 동일 BIOME4-SD McKenzie2003 설정을 고정하고 토심만 변화시킨 별도 계산에서 다음 경계가 확인되었다.

### 침엽수림 -> 개방식생
- H=0.01400 m: WHC 3.318 mm, PFT7 NPP 119.996, native biome 21, optPFT 10, reduced class 3
- H=0.01410 m: WHC 3.342 mm, PFT7 NPP 120.568, native biome 9, optPFT 7, reduced class 0
- 0.00001 m 간격 재검산에서 경계는 약 H=0.01401 m에서 나타났다.

즉 17.2 ka의 이 기후조건에서는 토심이 약 1.4 cm 아래로 감소하면서 PFT7 NPP가 BIOME4의 120 기준 아래로 내려가고 침엽수림이 개방식생으로 전환된다.

실제 동적모델의 초본 셀은 H=0.00930 m로 이 경계보다 얕고, 실제 침엽수림 271셀의 최소 토심은 0.04610 m이다.

### 개방식생 -> 무식생
- H=0.000200 m: native biome 27, reduced class 4
- H=0.000210 m: native biome 21, optPFT 10, reduced class 3
- 0.000001 m 간격 재검산에서는 전환이 약 H=0.000201 m 부근에 나타났다.

이 수치는 17.2 ka 고정기후 단일셀 민감도에서의 모델 내부 경계이며 일반적인 생태학적 보편 임계값으로 해석하지 않는다. 실제 17.2 ka 무식생 26셀은 최대 토심도 약 3.25e-6 m에 불과하여 이 경계보다 훨씬 얕다.

## 6. 하도와 수렴지형의 역할

무식생 26셀의 평균 flow slope 0.322는 침엽수림 271셀 평균 0.334와 거의 비슷하다. 따라서 단순히 경사가 더 가파르기 때문에 무식생이 된 것은 아니다.

대신:
- valley 비율: 88.46% 대 19.56%
- contributing area 중앙값: 5,311.6 대 816.4 m2, 약 6.5배
- A/w 중앙값: 14,486.2 대 43.77, 약 331배
- fluvial bedrock erosion: 무식생 평균 0.0992 m/kyr, 침엽수림 0

의 차이가 나타난다.

즉 이 셀들은 사면경사 자체보다 흐름이 집중되는 위치라는 점에서 구별된다. 토양이 존재하는 단계에서는 수렴된 흐름에 의한 regolith 제거가 가능하고, 토양이 거의 소진된 이후에는 regolith erosion 항은 공급제한으로 거의 0이 되며 같은 위치에서 bedrock erosion이 나타난다.

## 7. 4 ka 부근 활엽수림/혼효림 차이와의 구분

4.3 ka의 동적 활엽수림 8셀은 평균 토심 0.162 m, 범위 0.046-0.276 m이며 WHC도 평균 37.11 mm이다. 이들은 토양 자체가 소실된 셀이 아니다.

따라서 두 시기의 원인은 다음과 같이 구분한다.

- 17-20 ka 초기 침엽수림 불일치: 하도/수렴부에서 토심이 mm 수준 또는 0에 가까워지면서 PFT7이 BIOME4 NPP 한계 아래로 내려가 개방식생으로 전환되고, 추가 토양 소실 시 무식생이 되는 과정
- 4 ka 부근 활엽수림/혼효림 불일치: 수 cm에서 수십 cm의 토심이 남아 있는 산림 셀에서 WHC, wetness, firedays 변화가 산림 PFT 상대생산성을 바꾸고 일부 셀이 51% reduced-class 경쟁 경계를 넘는 과정

## 8. 논문용 결과 문단

17.2 ka의 동적모델에서는 298셀 가운데 271셀이 침엽수림, 1셀이 초본/개방식생, 26셀이 무식생으로 나타났다. 침엽수림 셀의 평균 토심과 WHC는 각각 1.819 m와 260.8 mm였으나, 초본/개방식생 셀에서는 0.0093 m와 2.20 mm로 감소하였고 무식생 셀의 토심은 사실상 0에 가까웠다. 무식생 셀의 88.5%(23/26)가 수렴지형으로 분류되어 침엽수림 셀의 19.6%(53/271)보다 높은 비율을 보였으며, contributing area의 중앙값도 각각 5,311.6 m2와 816.4 m2였다. 무식생 셀에서는 regolith 하천침식이 거의 나타나지 않은 반면 기반암 하천침식은 26셀 모두에서 나타났고 평균값은 0.099 m/kyr였다. 또한 19.8 ka의 불일치 4셀과 18.4-18.3 ka의 불일치 19셀은 모두 17.2 ka의 무식생 셀에 포함되었다.

## 9. 논문용 해석 문단

초기 침엽수림 시기의 국지적 불일치는 흐름이 집중되는 수렴부와 하도에서 토심이 크게 감소한 결과로 해석된다. 17.2 ka의 고정기후 민감도 계산에서는 토심이 약 0.014 m 아래로 감소할 때 PFT7의 잠재 NPP가 BIOME4의 120 gC m-2 yr-1 기준 아래로 내려가면서 침엽수림에서 개방식생으로 전환되었다. 실제 초본/개방식생 셀의 토심은 0.0093 m였으며, PFT6과 PFT7 NPP는 1.94 m 토심 조건보다 각각 약 79%와 65% 감소하였다. 토심이 추가로 소실된 셀에서는 BIOME4가 무식생을 산출하였고, 이들 셀에서는 현재 regolith가 거의 남지 않아 regolith 침식보다 기반암 하천침식이 나타났다. 따라서 이 시기의 식생 차이는 산림 PFT 간 상대적 우점 변화보다 하도 집중에 따른 토양 소진과 그에 수반된 생산성 붕괴가 핵심이며, 산림이 유지된 상태에서 PFT 경쟁비가 달라지는 4 ka 부근의 활엽수림-혼효림 차이와 구분된다.
