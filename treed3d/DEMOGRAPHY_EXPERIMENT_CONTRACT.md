# TREED3D demographic extension — experimental contract

This extension is **not vanilla TREED v1.0**. TREED v1.0 represents a community-average plant per grid cell and does not resolve short-term population dynamics. This module adds an explicitly separated demographic state for the 3D research simulator.

## Non-negotiable rules

1. The audited TREED physiology, carbon balance, soil-water coupling, Direct AGB and Pelletier geomorphology remain the baseline reference.
2. No renderer-only growth, PFT change, establishment or mortality may be presented as model output.
3. Every structural change shown in 3D must be present in the demographic state and must be generated by a model update.
4. The first prototype is deliberately one cohort / one cell. It validates carbon-to-height growth before establishment, mortality, understory and multi-PFT competition are added.
5. No fitted growth-rate coefficient is introduced in the first prototype.

## Parameter-free first growth experiment

The adult target strategy comes from the actual coupled TREED optimizer at the test cell.

TREED assumes that, under full local occupation, the number of representative plants is `cell_area / CA`. Therefore the cohort density is initialized from the adult TREED target as:

`density = 1 / CA_opt` [individual m-2].

The cohort begins at the TREED source initialization height `H = 0.5 m` while retaining the target leaf strategy (`a_ll`, `C_leaf`, seasonality, `r_s_r`). This isolates structural growth from trait evolution.

For a current cohort plant, the unmodified TREED physiology and soil-water fixed point provide the annual area-normalized net carbon gain `NCG` [g C m-2 yr-1]. Because TREED normalizes plant carbon terms by current crown area `CA`, carbon available to one representative individual is:

`DeltaC_ind = max(NCG, 0) * CA` [g C individual-1 yr-1].

The model's own allometric component pools define individual standing carbon:

`C_ind = C_leaf + C_fineroot + C_sapwood + C_heartwood + C_coarseroot`.

The next height is obtained by numerically inverting the unchanged TREED allometry for the height whose individual standing carbon equals `C_ind + DeltaC_ind`, bounded above by the actual TREED optimum height for the fixed environment. No empirical height-growth coefficient is used.

Cohort crown occupation is diagnosed as `density * CA` and cohort FPC as `density * CA * FPC_local`, capped at 1. At the adult target, `density * CA_opt = 1`, recovering the original TREED full-occupation assumption.

## What this first prototype does NOT yet include

- no establishment
- no mortality
- no understory
- no explicit PFTs
- no disturbance
- no daily demographic update

Those processes will only be added after this carbon/allometry experiment passes mass-balance and convergence tests, using separately audited reference formulations.
